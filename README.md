# Cisco Packet Tracer Coursework Networks

Welcome to the Cisco Packet Tracer Coursework Networks repository!

This repository contains a collection of network topologies and simulations created using **Cisco Packet Tracer** during coursework. The files and projects here serve as practical examples of network setup, routing, switching, and troubleshooting—ideal for students and professionals learning computer networking concepts.

***

## 📁 Repository Contents

- **PKT Files:** Network simulations and topology files for Cisco Packet Tracer.
- **Assignments:** Networks mapped as part of course assignments or lab exercises.

***

## 🚦 How to Use

1. **Install Cisco Packet Tracer:**  
   Ensure you have Cisco Packet Tracer installed on your machine. If you don’t have it, download the latest version from the official [Cisco Netacad](https://www.netacad.com/) website (free registration required).

2. **Clone or Download This Repository:**  

git clone https://github.com/J-Rakesh-Naidu/Cisco_Packet_Tracer.git

Or download the ZIP.

3. **Open PKT Files:**  
Launch Cisco Packet Tracer, then open the `.pkt` files to view and work with the provided network topologies.

4. **Experiment & Learn:**  
You can modify, expand, and test these network simulations to strengthen your understanding of networking principles.

***

## 📚 Topics Covered

- LAN/WAN design
- VLAN setup
- Routing protocols (e.g., RIP, OSPF, EIGRP)
- Static and dynamic routing
- Switch configuration
- Network troubleshooting
- DHCP, server integration, and more

_Note: Actual topics may vary based on the uploaded coursework files._
